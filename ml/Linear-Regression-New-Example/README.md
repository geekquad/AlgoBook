# Linear Regression

Linear Regression is a supervised machine learning algorithm used
to predict a continuous numerical value.

Example:
Study Hours → Student Score

The model tries to find the best-fitting straight line between
the input and target values.

Steps:
1. Load the dataset
2. Split data into training and testing sets
3. Scale the features
4. Train the Linear Regression model
5. Make predictions
6. Evaluate the model

Evaluation metrics:
- MAE
- MSE
- R² Score
